# Nimbus

Nimbus - AI meeting notes that write themselves. iOS 27 inspired product site.

Built with **React 18 + Vite 5** and **Framer Motion**, styled from scratch with an iOS 27 design language:
Liquid Glass materials, SF Pro typography (Inter fallback off Apple devices), system colors,
segmented controls, switches, sheets and automatic light / dark mode.

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Vercel

1. Import this repository at https://vercel.com/new
2. Framework preset: **Vite** (build `npm run build`, output `dist`), already set in `vercel.json`
3. Deploy
